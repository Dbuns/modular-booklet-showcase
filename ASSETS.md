# Asset provenance

This repository contains fictional demonstration material rather than photographs or identifying information about real people.

## Generated character imagery

`assets/showcase/marmot-personnel-sheet.png` is AI-generated imagery supplied for this project by the repository owner. The five small `marmot-*.svg` files are crop wrappers around that sheet; they do not contain separate embedded photographs.

`assets/showcase/marmot-audience-icon.png` is a small fictional marmot symbol used to demonstrate optional audience markers.

Anyone publishing a derivative project should replace these files or confirm that their intended use complies with the terms that applied when their generated imagery was created.

## Project-created demonstration assets

The following simple diagrams and interface examples were created specifically for the showcase:

- `folder-icon.svg`;
- `image-placeholder-landscape.svg`;
- `showcase-cover-spread.svg`;
- `workflow-placeholder.svg`;
- `qr-example.png`, which represents an `example.com` demonstration link.

They contain no logos, personal data, or internal organizational information.

## Fonts

The project references Arial but does not redistribute any font files. Arial must be available on the computer running Typst. A derivative project may select another installed font in `content/theme.toml`, subject to that font's own license.
